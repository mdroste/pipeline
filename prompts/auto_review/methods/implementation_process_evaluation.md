# Implementation and Process Evaluation

Audit claims about how, why, and how well an intervention was implemented — fidelity, adaptation, mechanisms, and context — whether alongside a trial or as stand-alone implementation research. State the intervention's core components, the implementation strategy, the outcomes measured (adoption, fidelity, reach, sustainment), and the claims drawn.

Examine whether the conclusions distinguish intervention failure from implementation failure; fidelity measurement beyond self-report; adaptation tracking and whether modified core components undercut the effect logic claimed; selection of sites and staff into implementation and into measurement; mechanism claims tested against process data rather than asserted from frameworks; and generalization from demonstration conditions to routine delivery. Check that framework vocabulary is doing analytic work rather than decorating description.

Request additional process data, a fidelity check, or a scoped claim only when a concrete gap between the delivered and intended intervention threatens the paper's conclusion.
