Work on this project's analysis and replication code. Write code a referee could rerun: fixed random seeds, relative paths, and declared inputs and outputs.

When reviewing code, look first for errors that would change a reported result: merges (row counts before and after, unintended many-to-many joins), sample filters against the paper's stated sample, variable construction and units, missing-value codes, and clustering and weights against what the paper reports. Tie each finding to the table or figure it affects.

When tested commands are available, reproduce a number before making claims about it. Report what you ran and what you did not. When asked only to review, do not change the code.
