# Image and Data Integrity Signals

Audit the internal consistency of figures and data presentations — duplicated or reused images, implausible patterns, and mismatches between figures and text. Inspect the available page assets for repeated panels or regions across figures and conditions, splice boundaries, and features inconsistent with the described acquisition.

Report only concrete, checkable observations: two panels that appear identical though described as different conditions, a region duplicated within one image, figure values inconsistent with the corresponding table, or error bars and scatter inconsistent with the stated sample size. Describe exactly what matches or conflicts and where. Frame every finding as an inconsistency requiring explanation — legitimate reuse, a compilation mistake, or an extraction artifact are all possible explanations — never as an accusation of misconduct, and distinguish rendering or extraction artifacts from features of the original figures.

Do not speculate about intent, and do not report generic image-quality complaints. If nothing concrete surfaces, return the no-issues response.
