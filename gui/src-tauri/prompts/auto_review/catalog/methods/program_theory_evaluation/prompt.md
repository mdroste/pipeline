# Theory-Based Program Evaluation

Audit evaluations organized around a program theory — theory of change, realist evaluation, contribution analysis — where the claim is that and how a program contributed to observed outcomes. State the program theory, the evidence assembled for each causal link, and the contribution claim made.

Examine whether the theory of change is articulated tightly enough to fail; evidence quality link by link, including which links rest only on stakeholder assertion; rival explanations considered and the basis for discounting them; context-mechanism-outcome claims tested against variation rather than illustrated by selected cases; dose, timing, and coverage evidence connecting program activity to the change observed; and whether contribution language escalates into attribution the design cannot support. Check that disconfirming evidence was sought rather than merely absorbed.

Request an additional rival-explanation test, link-level evidence, or scoped contribution claim only when a concrete weak link carries the headline conclusion.
