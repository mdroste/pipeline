# Life-Cycle Assessment

Audit environmental claims from life-cycle assessment. State the functional unit, system boundaries, allocation choices, inventory data sources and vintages, and the impact categories carrying the conclusions.

Examine functional-unit equivalence in comparative claims; boundary truncation and cutoff rules that exclude burdens concentrated in one alternative; allocation versus substitution choices and their directional effect on the comparison; inventory-data representativeness for the region, technology, and period claimed; attributional results used to answer consequential questions; impact-category selectivity, especially conclusions led by one category while others worsen; and sensitivity coverage of the assumptions that actually drive the ranking. Check that "greener than" conclusions survive the disclosed sensitivity range.

Request a boundary extension, alternative allocation, or added impact category only when a concrete methodological choice plausibly reverses the comparative environmental claim.
