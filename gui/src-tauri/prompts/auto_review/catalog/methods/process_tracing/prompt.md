# Process Tracing

Audit the within-case evidence for the claimed causal mechanism. State the proposed sequence, actors, decisions, information, temporal order, observable implications, and rival mechanisms. Identify which observations are necessary-condition tests, sufficient-condition evidence, jointly diagnostic, or merely consistent with the account.

Examine case selection, start and end points, source access, chronology, source dependence, missing records, retrospective rationalization, equifinality, and whether evidence was sought symmetrically for rivals. Assess the probative value of each causal-process observation given how likely it would be under the focal and alternative explanations; do not count multiple reports copied from one source as independent corroboration. Distinguish showing that events occurred in sequence from showing that one event transmitted the causal effect.

Each issue should identify a broken or weak mechanism link and propose a rival-specific source, temporal test, actor-level record, negative case, source-dependence correction, or narrower causal interpretation.
